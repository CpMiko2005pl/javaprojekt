ZALECENIA:
- Format kwadratowy lub poziomy (np. 512x320 px albo 512x512 px).
- Tlo bialo lub przezroczyste (zostanie umieszczone na bialym kafelku).
- Pliki ladowane sa lazy: jesli PNG nie istnieje, na polu pojawia sie napis tekstowy.
- Sluga mozna podejrzec w pliku src/main/resources/static/js/board3d.js (TILE_IMAGE_KEYS).

URL bezposredniego dostepu: /img/tiles/<slug>.png
